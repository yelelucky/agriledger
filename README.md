# AgriLedger

Paddy trading, government procurement (agency), farmer advances and payments ledger for Sethji and Sons.

- Open the app: https://yelelucky.github.io/agriledger/
- Setup steps (Google Sheet + phone): https://yelelucky.github.io/agriledger/SETUP-GUIDE.html

The app keeps its data on the phone and copies entries to the owner's Google Sheet. This repository holds only the app code; it contains no business data and no keys.
